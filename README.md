# LOBlossom

理解が育ち、花咲いていく学習サービス。

## コンセプト

LOBlossom は「知識を増やす」のではなく、「理解を育て、花咲かせる」ことを目的とした学習サービスです。

- 学習者が自分の言葉で AI に説明する（フェイマン・テクニック）
- AI コーチが伴走し、理解の軌跡を磨く
- 毎回の学習成果を **理解の軌跡** として残す

- Next.js 15（App Router）
- TypeScript
- Tailwind CSS 4

## 開発

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

```bash
# 本番ビルド
npm run build

# Lint
npm run lint
```
